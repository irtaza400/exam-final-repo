The following paths are independent functional paths.

1. CLEANROOM TELEMETRY PATH

   Sensor Simulator
   ↓
   topic127/raw/cleanroom
   ↓
   Mosquitto
   ├──► MQTT → InfluxDB Ingestion → InfluxDB Storage → Grafana
   │
   └──► Edge Gateway → topic127/edge/validated → Custom Edge AI
   ├──► AI Result
   └──► AI Alert

2. INDUSTRIAL PROCESS SECURITY PATH

   OPC-UA Simulator → OPC-UA Server → OPC-UA Client Validator
   → Process Security Evidence

   Modbus Simulator → Modbus Server → Modbus Client Validator
   → Process Security Evidence

The process-security paths do NOT feed the Custom Edge AI output.

ARCHITECTURE BOUNDARIES
=======================

[IMPLEMENTED]

• Cleanroom sensor simulation
• Raw MQTT telemetry
• Mosquitto messaging
• Edge Gateway validation / enrichment / routing
• Validated MQTT
• Custom rule-based Edge AI
• MQTT → InfluxDB ingestion
• InfluxDB time-series storage
• Grafana monitoring
• FUXA operational visualization
• OPC-UA process simulation / validation
• Modbus PLC simulation / validation
• SHA-256 recipe integrity
• Supply-chain validation / risk / hash-chain ledger
• Ledger verification
• EHS incident engine
• Suricata controlled IDS demonstration
• Bandit / Semgrep / Trivy
• Incident Manager
• Audit Logger
• Compliance Report Generator
• Final Report Generator

[SIMULATED / CONTROLLED]

• Physical cleanroom sensors
• Semiconductor manufacturing equipment
• PLC hardware
• Worker-safety instrumentation
• Industrial network traffic
• Physical safety systems
• Production chemical infrastructure

[IMPORTANT LIMITATIONS]

• Custom Edge AI is rule-based inference, not a trained ML model.
• scikit-learn and TensorFlow/Keras are separate demonstration workflows.
• scikit-learn and TensorFlow/Keras are not direct InfluxDB downstream consumers.
• Suricata is not continuous enterprise IDS monitoring.
• Incident Manager is not a universal evidence bus.
• Audit Logger is not a live enterprise SIEM/SOAR stream.
• Compliance reporting does not provide regulatory certification.
• EHS and industrial responses are generated recommendations / evidence.
• The supply-chain ledger is a single-node educational hash chain.
• The platform is an educational proof-of-concept, not a production
semiconductor fabrication control system.

Topic 127 Educational Manufacturing Security Platform

• INDEPENDENT DEMONSTRATION WORKFLOWS
• SECURITY / SAFETY CONTROLS
