EDGE AI DECISION LOGIC
Supported conditions include:
particle_count
temperature
humidity
airflow
gas_ppm
ppe_compliant

Risk score:
weighted active-metric score

Severity:
CRITICAL
if risk score >= configured critical threshold
OR any individual metric is critical

WARNING
if risk score >= configured warning threshold

NORMAL
otherwise

CONFIGURED THRESHOLDS
particle_count:
warning = 800
critical = 1200
temperature:
minimum = 18
warning_high = 26
critical_high = 30
humidity:
minimum = 35
warning_high = 55
critical_high = 65
airflow:
warning_low = 0.30
critical_low = 0.20
gas_ppm:
warning = 50
critical = 75
PPE non-compliance:
critical metric condition

RECOMMENDED RESPONSES
Particle anomaly
→ inspect contamination source and filtration controls
Airflow anomaly
→ inspect airflow / pressure / ventilation
Gas anomaly
→ initiate EHS gas-safety verification
PPE non-compliance
→ suspend unsafe work until compliance restored
Temperature / humidity anomaly
→ verify environmental control and process conditions

IMPORTANT:
These are executable risk-analysis and recommendation workflows.
They are not represented as autonomous physical actuation systems.

CONTROLLED TAMPER SCRIPT CONTRACT
Validator exit code:
0 = recipe integrity verified
1 = runtime/configuration failure
2 = recipe tampering detected
The wrapper treats exit code 2 as the EXPECTED security-detection outcome
and ultimately returns success after detection, evidence generation,
restoration and revalidation.
