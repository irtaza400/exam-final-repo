========================================================================================================================
SECURITY ARCHITECTURE LIMITATIONS
The current repository is an educational proof-of-concept.
Therefore this A05 diagram does NOT claim:
• Production-grade OT security
• Live enterprise SOC/SIEM operation
• Enterprise SOAR automation
• Certified safety-instrumented systems
• Regulatory certification
• Legal compliance certification
• Production-grade IAM
• Enterprise secrets management
• High-availability security infrastructure
• Continuous live network IDS deployment
• Physical industrial safety certification

The project demonstrates executable security controls, validation,
risk assessment, anomaly detection, traceability, incident evidence,
audit recording and compliance-oriented reporting using controlled
laboratory software and simulated/controlled inputs.
