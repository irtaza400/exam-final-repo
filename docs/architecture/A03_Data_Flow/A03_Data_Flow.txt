A03 — Topic 127 Data Flow Architecture
========================================================================================================================
                     TOPIC 127 — DATA FLOW ARCHITECTURE
  Telemetry • Validation • Analytics • Process Data • Supply Chain • EHS • Security • Evidence • Reporting
========================================================================================================================

IMPORTANT ARCHITECTURE RULE
A03 shows the FLOW OF DATA / INFORMATION.
A01 = functional components
A02 = deployment / network placement
A03 = data movement, transformation, storage and evidence generation
A04 = operational process / workflow logic
A05 = security controls and trust boundaries
A06 = current-to-target cloud / hybrid architecture
A03 deliberately avoids pretending that independently implemented
demonstration modules are one continuous production data pipeline.

18. DATA FLOW LIMITATIONS / ACCURACY NOTES
• Mosquitto is a publish/subscribe broker, not a sequential processing step.
• MQTT-to-InfluxDB ingestion subscribes directly to: topic127/raw/cleanroom
• Edge Gateway independently subscribes to: topic127/raw/cleanroom
• Edge Gateway publishes: topic127/edge/validated, topic127/edge/rejected, topic127/edge/status
• Custom Edge AI consumes: topic127/edge/validated
• Custom Edge AI publishes: topic127/edge/ai/result, topic127/edge/ai/alert
• scikit-learn and TensorFlow/Keras anomaly workflows are separate demonstration paths.
• OPC-UA and Modbus are separate server/validator paths.
• Recipe integrity compares a calculated current SHA-256 with the stored approved hash.
• Supply-chain processing uses supplier validation, risk evaluation, ledger creation, and independent chain verification.
• Incident Manager aggregates a fixed set of operational incident CSVs; it is not a universal evidence bus.
• Audit Logger is a standalone demonstration logger.
• Compliance Generator maps a defined seven-file evidence set to report content; it is not a regulatory certification engine.
• Final Report Generator consolidates/checks the broader project evidence set and writes final_project_report.md.
• The supply-chain ledger is a single-node educational hash-chain, not a distributed blockchain network.
• Physical industrial and cleanroom assets are simulated or represented by controlled demonstration data.
