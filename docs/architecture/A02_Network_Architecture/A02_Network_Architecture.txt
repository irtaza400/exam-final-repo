19. IMPORTANT DEPLOYMENT / NETWORK LIMITATIONS
==============================================

• Current implementation is a single EC2 host deployment.
• Docker uses a bridge network rather than Kubernetes.
• Industrial servers run as host-side Python processes.
• FUXA runs in Docker and reaches host-side OPC-UA services through
host.docker.internal.
• The MQTT-to-Influx writer supports raw-topic standalone mode and
validated-topic complete-lab mode.
• The complete-lab runtime explicitly sets:
MQTT_TOPIC=topic127/edge/validated
• Custom Edge AI is rule-based inference.
• scikit-learn and TensorFlow/Keras are separate demonstration workflows.
• Suricata is controlled PCAP analysis rather than continuous production IDS.
• Listed Security Group ports are examination/demo exposure, not a
production firewall recommendation.
