========================================================================================================================
                                             IMPLEMENTATION STATUS
========================================================================================================================

 [IMPLEMENTED]
 AWS EC2 deployment, Ubuntu host, Docker Compose, Docker bridge network,
 Mosquitto, InfluxDB, Grafana, FUXA, host-side Python services, OPC-UA,
 Modbus and supporting project services.

 [SIMULATED]
 Physical cleanroom sensors, semiconductor manufacturing equipment and
 PLC/industrial equipment are represented by software simulation.

 [DEMONSTRATION EXPOSURE]
 Ports documented for examination/demo access should not be interpreted as
 a recommended production security-group configuration.

 [TARGET / FUTURE]
 Production OT/IT segmentation, private networking, hardened firewall rules,
 encrypted protocol deployment, high availability and enterprise identity
 controls are future production improvements.


========================================================================================================================
                                                   LEGEND
========================================================================================================================

   Container                  = Dockerized service
   Host Service               = Python process running on EC2 host
   :PORT                      = Network endpoint / published port
   ↓                          = Data / control flow
   ─────────►                 = Network communication
   ZONE                       = Logical network / trust boundary
   *                          = Optional security-demo profile

   The diagram reflects the CURRENT EDUCATIONAL DEPLOYMENT MODEL.
   It does not claim that the system is a production semiconductor fab network.
